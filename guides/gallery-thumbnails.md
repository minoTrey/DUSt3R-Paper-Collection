# Gallery thumbnails

The approved Foundation set contains CroCo, CroCo v2, DUSt3R, MASt3R and VGGT. Their dedicated English landscape illustrations retain the source posters' cream/forest-green palette. They show a short method name, an input/output caption and one conceptual scene, with no benchmark measurements. The gallery chrome retains its existing white/navy palette. Full-size visual summaries remain in the detail pages.

CroCo and CroCo v2 show **cross-view RGB completion during pre-training**: a masked target and an unmasked reference from another viewpoint reconstruct target-view RGB patches. This follows [CroCo Section 3 / Figure 3](https://arxiv.org/html/2210.10716v2) and [CroCo v2 Section 3 / Figure 2](https://arxiv.org/html/2211.10408v3). CroCo v2 stereo disparity and optical flow require downstream fine-tuning; these are not its RGB pretext outputs. All artwork is illustrative rather than measured model output.

## Original and delivery records

[paper-thumbnails.json](../data/paper-thumbnails.json) records canonical paper IDs, primary source identities, original PNG paths/dimensions/hashes, prompts, alt text and review scope. Its separate `delivery` record identifies a 960×540 WebP and the reviewed PNG it came from. The five generated PNGs are retained unchanged. Full-image containment/padding and Lanczos resizing produce the web derivatives, with WebP quality 85 and method 6. No poster or thumbnail is cropped. The five delivery assets total **564,056 bytes**, compared with **11,797,530 bytes** for the generated PNG masters.

[thumbnails.mjs](../site/thumbnails.mjs) validates both originals and deliveries. The site copies and loads only optimized listing art, while preserving the 337 original visual-summary posters for details. Desktop and mobile use 16:9 frames with `object-fit: contain`; mobile images span the card width for readable names and captions. Missing or failed art uses an explicit text fallback, never a cropped full poster.

## Remaining production handoff

The other **332** papers have not been generated by this change. [thumbnail-production-inventory.json](../data/thumbnail-production-inventory.json) supplies unassigned canonical IDs, source links/revisions as recorded, note/poster hashes, output destinations, open source issues and the common design/review specification. The parent coordinates ownership before parallel generation. Recheck the current thumbnail manifest and migrations before claiming/importing a job; the five Foundation IDs are excluded.

Read each matching original paper before deciding on a caption or diagram. Distinguish pre-training, inference dependencies and downstream fine-tuning. Resolve FVO/CalfVO, IDT/MVID and FlowR source issues before making content claims for those jobs. The handoff inventory is a production snapshot, not fresh source verification or an instruction to generate all images automatically.

```sh
python tools/build_thumbnail_inventory.py
python tools/build_thumbnail_inventory.py --check
node --test site/build.test.mjs site/thumbnails.test.mjs
node site/build.mjs --out _site-thumbnails --thumbnail-preview
node site/check.mjs _site-thumbnails
python site/serve.py --directory _site-thumbnails --port 4177
```

The optional `/thumbnail-preview/` study is generated only with `--thumbnail-preview`. The actual gallery `?category=foundation` contains all five thumbnails in publication-year order. Run `node site/test-thumbnail-browser.mjs` against the local server, or set `SITE_URL` to the approved public gallery after deployment. Reports and screenshots are ignored under `site-test-results/foundation-thumbnails/`. The check covers all five images at 1440/768/390/360px, failed-image fallback, filtered-gallery requests and original detail preservation.

The static checker validates all 337 canonical poster hashes and 5,089 detail links, plus the five delivery hashes and 332 text fallbacks. Thumbnail regressions cover canonical source identity, separate paths, original/delivery byte integrity and actual PNG/WebP dimensions. Existing permissions, credentials and discovery schedules are unchanged.
