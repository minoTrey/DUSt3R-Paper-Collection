## 🎬 Overview

Recover geometry as the scene changes over time. Time-varying geometry, deformation or temporal correspondence must be central to the problem. A moving camera, streaming input or generic persistent memory alone does not make a scene dynamic. Dynamic Gaussian methods can instead be filed under [Gaussian Splatting](../gaussian-splatting/) when splat representation and rendering are the main contribution. The [classification review](../../data/classification-review-2026-10-19.json) explicitly retains unresolved boundary cases rather than silently moving them.

**Reading tags:** motion · deformation · persistent state · tracking.
