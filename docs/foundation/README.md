## 🔬 Overview

The core starting points for this DUSt3R collection: **CroCo, CroCo v2, DUSt3R, MASt3R and VGGT**. Read cross-view pretraining, pairwise geometry, 3D-grounded matching and multi-view prediction as distinct contributions. Inclusion here is a reading-route choice, not a claim that these models share one architecture or use the same inference protocol.

Follow [Model Extensions](../extensions) for efficiency/compression, adaptation/reliability and further pretraining. [3D Reconstruction](../reconstruction) contains reconstruction and matching systems, including MASt3R-SfM and RoMa-Ω. Benchmarks belong to [Surveys, Benchmarks & Analysis](../surveys).

**Reading tags:** cross-view pretraining · pairwise pointmaps · matching · multi-view geometry.
