## 🤖 Overview

Robot policy, action, embodiment-specific calibration, multi-robot collaboration or onboard constraints must be central to the method and its evaluation. Geometry that could be used by a robot is not sufficient. General joint map-and-trajectory SLAM belongs in [3D Reconstruction](../reconstruction/); general pose, registration, localization and visual odometry belong in [Pose Estimation](../pose/).

This folder retains Calib3R, Robo3R, LG-VLN, Unifying Scene Representation and Hand-Eye Calibration, CoMo3R-SLAM and Noctif3R, and adds Adapt3R. CoMo3R-SLAM contributes multi-robot collaboration; Noctif3R addresses onboard execution constraints. These two boundary choices remain explicit rather than treating all SLAM as Robotics.

**Reading tags:** robot calibration · SLAM · navigation · interaction.
